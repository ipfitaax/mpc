# MPC Professional IT Career Program

**Mogadishu Professional Certificate (MPC) — Soobe, Mogadishu, Somalia**

One-Year Curriculum Model · Course Catalog · Certificate Framework

Version 1.0 — September 2026

---

## 1. Purpose of This Document

This document defines a complete, teachable model for MPC's one-year IT program. It answers four questions:

1. **What can a graduate actually do?** — a written job profile, not a topic list.
2. **What courses exist, in what order, and for how many hours?**
3. **How is each course assessed, and when is a certificate issued?**
4. **What is missing from the current MPC offering, and what should be added?**

Every course in this model is a standalone, certificate-bearing unit. A student may enrol in a single course and receive an MPC Course Certificate for it. Students who complete groups of courses receive higher stage awards, up to the full Professional Diploma.

---

## 2. The Graduate Profile — What a Student Can Do After One Year

The program is built backwards from a single sentence:

> **A graduate can walk into a small or medium Somali business and take full responsibility for its computers, its office network, its documents, and its website.**

Broken into verifiable job tasks, the graduate can:

**Computers and operating systems**

- Assemble a desktop PC, identify every component, and diagnose a machine that will not boot.
- Install and configure Windows 10/11 from USB media, including drivers, updates, user accounts and activation.
- Install and configure Linux (Ubuntu Server and Ubuntu Desktop), including partitioning, users, permissions and package management.
- Dual-boot a machine, create a bootable recovery USB, and image or clone a working system.
- Diagnose and repair common faults: no display, no boot, slow performance, virus infection, corrupted profile, failing disk, overheating, driver conflicts.
- Back up and restore user data, and recover files from a failed installation.

**Office network and printing**

- Plan and cable a small office network: terminate UTP cable, crimp RJ45, test with a cable tester, mount a patch panel and switch.
- Configure a router, DHCP scope, static IP plan, subnet mask and gateway for a 10–50 user office.
- Configure Wi-Fi with WPA2/WPA3, guest isolation and channel planning.
- Set up file sharing and shared folders with permissions, on Windows and on Linux (Samba).
- Install a network printer, share it, install drivers on all client machines and fix common printing faults.
- Troubleshoot connectivity with ping, ipconfig/ip, tracert, nslookup and a structured method.

**Documents and office software**

- Produce professional documents in Word: letterhead, multi-section reports, table of contents, mail merge, styles, templates.
- Build working spreadsheets in Excel: formulas, absolute references, lookup functions, pivot tables, charts, data validation, printable reports.
- Design and deliver a presentation in PowerPoint.
- Create, edit, merge, split, protect and fill PDF forms; scan and OCR paper documents.
- Manage files and records: naming conventions, folder structures, versioning, cloud sync and shared drives.
- Type accurately in both Latin and Somali text, and format Arabic-script or right-to-left content when required.

**Web design and web development**

- Build a responsive multi-page website from scratch with HTML5 and CSS3, working correctly on phone and desktop.
- Add interactivity with JavaScript: form validation, image sliders, menus, dynamic content.
- Build a small database-driven web application with PHP and MySQL: login, add/edit/delete records, search, reports (for example a student registration system, a shop inventory, a clinic appointment book).
- Register a domain name and rent hosting, configure DNS records, upload a site by FTP/cPanel, install an SSL certificate, and set up a business email address.
- Install and customise WordPress for a client who needs a site quickly.

**Security and professional practice**

- Apply basic security: strong passwords, password manager, MFA, patching, antivirus, safe browsing, phishing recognition, and a simple backup routine.
- Log, prioritise and close support tickets, and write a clear fault report.
- Write a CV, present a portfolio of real projects, and handle a technical interview.

**Target entry-level roles:** IT Support Technician · Computer Lab Technician · Network Support Technician · Office IT Officer · Junior Web Developer / Web Designer · ISP or Internet-café Support Staff · Data Entry and Office Administration Officer.

## 3. Review of MPC's Current Offering

### 3.1 What is already right

| Strength | Comment |
|---|---|
| Two entry pathways (12-month and 6-month) | Correct market fit — one for school leavers, one for career switchers who need speed. |
| Modular structure with portfolio evidence per module | This is the right pedagogy. Keep it and formalise it. |
| Career support built in (CV, interview, portfolio) | Rare in the local market and a real differentiator. |
| Certificate tied to stated attendance and assessment rules | The correct principle. It now needs published numbers. |
| A+, CCNA and Data Analysis already offered | A ready-made specialisation layer sitting above the core program. |

### 3.2 Gaps found — and what this model does about them

| # | Gap in the current offering | Impact | Fix in this model |
|---|---|---|---|
| 1 | The nine modules are described only as themes ("computer fundamentals", "networking", "data skills"). No names, no hours, no outcomes. | Students cannot compare MPC with a competitor; instructors teach inconsistently; certificates cannot be defended. | Section 4: 12 named courses, each with a code, hours, outcomes, project and assessment. |
| 2 | **Linux is absent from the core.** | The graduate profile requires Linux installation and administration. Employers with servers, ISPs and hosting companies will not hire without it. | **IT-201 Linux Installation & System Administration (60 h)** made core, not optional. |
| 3 | **Web design, web development, hosting and domains are listed as "optional specialisations, where instructors and equipment permit."** | This is the single most requested and most sellable skill set in Mogadishu, and it is the part of the request the program must deliver. Leaving it optional makes it unreliable. | Terms 3 and 4 make web design, JavaScript, PHP/MySQL and hosting **core, 174 hours combined**. |
| 4 | No published prerequisite chain or course order. | Students enrol in the wrong course, drop out, or repeat content. | Section 5: a fixed sequence with explicit prerequisites and a dependency map. |
| 5 | No per-course certificate. | A student who completes one course leaves with nothing to show, so short-course revenue is lost. | Section 6: MPC Course Certificate for every unit, plus four stage awards. |
| 6 | Security is not named anywhere. | Employers now ask about it; it is also the fastest-growing course category. | **IT-302 IT Security & Data Protection Essentials (36 h)** added as core. |
| 7 | No stated weekly hours, total hours or credit value. | Cannot be recognised by employers, ministries, or partner institutions. | 12 hours/week × 48 teaching weeks = **576 contact hours**, mapped per course. |
| 8 | A+, CCNA and Data Analysis are sold separately with no relationship to the program. | Students do not know where these fit or whether they duplicate the program. | Section 8: a specialisation layer that sits **after** the diploma, with duplicate content removed. |
| 9 | No lab or equipment specification. | Quality varies by campus and by intake. | Section 9: minimum lab requirements per course. |
| 10 | Practical exams are implied but not defined. | "Practical assignments instead of theory alone" is a claim without a mechanism. | Section 6.3: every course ends in a timed practical exam on real equipment. |

### 3.3 Two recommendations that change the business, not just the syllabus

**A. Sell the same courses three ways.** Build the catalog once, then package it as (a) the 12-month diploma, (b) the 6-month intensive, and (c) individual short courses. One set of materials, three price points, three audiences. Section 7 shows the mapping.

**B. Make the 6-month intensive an exit point of the 12-month program, not a separate product.** Today they are described as two different programs. If the 6-month program is exactly Terms 1 and 2 delivered at 24 hours/week, then a 6-month graduate can return later and continue into Terms 3 and 4 with full credit. That converts a one-time student into a returning one.

#### IT-101 · Computer Hardware & IT Essentials
**48 hours · No prerequisite · Aligned to CompTIA ITF+ and A+ Core 1**

*What the student can do at the end:* strip and rebuild a desktop PC, name and test every component, and correctly diagnose a machine that does not power on or does not display.

**Topics**

1. How a computer works: CPU, RAM, storage, motherboard, power supply, cooling.
2. Number systems and units: binary, hexadecimal, bits vs bytes, storage and speed measurement.
3. Inside the case: identifying motherboard form factors, chipsets, expansion slots, connectors.
4. Storage: HDD vs SSD vs NVMe, partitions, file systems, health checking.
5. Memory: types, capacity, dual channel, diagnosing bad RAM.
6. Power: PSU wattage, voltages, surge protection, UPS sizing for a Somali office with unstable mains.
7. Peripherals and ports: USB standards, HDMI/VGA/DisplayPort, printers, scanners, projectors.
8. Mobile and laptop hardware: batteries, screens, keyboards, common repairs.
9. Safety and workshop practice: ESD, tools, cable management, workspace discipline.
10. Structured troubleshooting: the six-step method, isolating a fault, documenting a repair.

**Practical labs:** full disassembly and reassembly (×3, timed) · POST beep-code diagnosis · RAM and disk swap · PSU test · faulty-machine triage station (instructor plants 10 faults, student finds them).

**Course project:** *Bench Repair Log* — diagnose and repair five faulty machines, with a written fault report for each (symptom, diagnosis, action, result, parts, time).

**Assessment:** Practical exam 40% · Labs 30% · Written test 20% · Attendance 10%

#### IT-102 · Windows Installation, Configuration & Troubleshooting
**60 hours · Prerequisite: IT-101 · Aligned to CompTIA A+ Core 2**

*What the student can do at the end:* install Windows 11 on a bare machine from USB, configure it fully for a business user, and repair a Windows installation that will not start.

**Topics**

1. Windows editions and licensing; hardware requirements; choosing an edition for a client.
2. Creating bootable installation media; BIOS/UEFI settings, boot order, Secure Boot.
3. Partitioning schemes: MBR vs GPT, planning disk layout, clean install vs upgrade.
4. Installation walkthrough — Windows 11 and Windows 10 — offline account creation, regional settings.
5. Drivers: identifying unknown devices, sourcing drivers, driver rollback.
6. User accounts, local groups, standard vs administrator, UAC.
7. Windows Update, activation, and post-install checklist.
8. File system and NTFS permissions; sharing a folder; mapped drives.
9. Software deployment: installing, repairing and cleanly removing applications.
10. Maintenance: Task Manager, Services, Event Viewer, Disk Cleanup, defragment vs TRIM.
11. Backup and recovery: File History, system image, restore points, recovery drive, resetting a PC.
12. Malware: symptoms, removal procedure, Windows Defender, safe browsing.
13. Command line and PowerShell basics: ipconfig, sfc, chkdsk, DISM, net user, tasklist.
14. Repairing a dead installation: Safe Mode, WinRE, startup repair, bootrec, BCD.
15. Dual-boot with Linux (prepares IT-201).

**Practical labs:** timed clean install (target: under 40 minutes end to end) · driver hunt on an unbranded machine · broken-boot recovery station · user-data rescue from a non-booting PC · imaging a lab machine and restoring it to three others.

**Course project:** *Office PC Build-Out* — take three bare machines to a documented, business-ready state: OS, drivers, accounts, office software, antivirus, backup, printer, and a signed handover checklist.

**Assessment:** Practical exam 45% · Labs 30% · Written test 15% · Attendance 10%

### TERM 2 — Operating Systems & Networking (144 hours, Weeks 13–24)

#### IT-201 · Linux Installation & System Administration
**60 hours · Prerequisite: IT-102 · Aligned to CompTIA Linux+ (introductory level)**

*What the student can do at the end:* install Ubuntu Server, manage it entirely from the command line, and run it as a file, print and web server for a small office.

**Topics**

1. What Linux is and where it is used; distributions; choosing Ubuntu LTS.
2. Installing Ubuntu Desktop and Ubuntu Server; partitioning, LVM basics, swap.
3. Dual-boot and virtual machines (VirtualBox / Hyper-V) as a safe practice environment.
4. The shell: navigation, paths, `ls cd pwd cp mv rm mkdir find`, wildcards, tab completion.
5. Files and text: `cat less head tail grep nano vim`, redirection and pipes.
6. Users and groups: `useradd usermod passwd groups`, `/etc/passwd`, `sudo` and `visudo`.
7. Permissions: `chmod chown`, octal notation, umask, special bits.
8. Packages: `apt`, repositories, updates, `.deb` files, `snap`.
9. Processes and services: `ps top kill systemctl journalctl`, enabling services at boot.
10. Storage: `df du mount fstab`, adding and formatting a second disk, USB media.
11. Networking on Linux: `ip`, netplan, static addressing, `ping ss dig`, hostname resolution.
12. Remote administration: SSH, key-based login, `scp`, basic firewall with `ufw`.
13. Services: Samba file sharing to Windows clients, CUPS printing, Apache web server.
14. Scheduling and scripting: `cron`, a first bash script, backup automation with `tar` and `rsync`.
15. Logs and troubleshooting: where logs live, reading them, recovering a system that will not boot.

**Practical labs:** install Ubuntu Server from ISO · build a Samba share that Windows PCs can map · SSH-only administration day (no GUI allowed) · write a nightly backup script and schedule it · break-and-fix: instructor corrupts fstab/permissions, student recovers.

**Course project:** *Small Office Linux Server* — deliver an Ubuntu Server providing shared folders with per-department permissions, a shared printer, an internal website, automated nightly backups, and SSH admin access — with written documentation.

**Assessment:** Practical exam 45% · Labs 30% · Written test 15% · Attendance 10%

#### IT-202 · Network Fundamentals & Cabling
**60 hours · Prerequisite: IT-101 · Aligned to CompTIA Network+ (N10-009)**

*What the student can do at the end:* design, cable, address and troubleshoot a small office network.

**Topics**

1. What a network is; LAN, WAN, MAN; client-server vs peer-to-peer.
2. The OSI and TCP/IP models used as a troubleshooting tool, not a memory exercise.
3. Media and cabling: UTP categories, fibre basics, coax, wireless; distance limits.
4. Hands-on cabling: straight-through and crossover, RJ45 crimping, punch-down, patch panel, cable tester, labelling standards.
5. Devices: hub, switch, router, access point, modem, firewall — what each actually does.
6. Ethernet and switching: MAC addresses, ARP, collision vs broadcast domains, basic VLAN concept.
7. IPv4 addressing: classes, private ranges, subnet masks, gateway; **subnetting practice until fluent**.
8. IPv6 introduction: address format, why it exists, dual stack.
9. DHCP: how leases work, configuring a scope, reservations, troubleshooting.
10. DNS: resolution process, record types (A, CNAME, MX, TXT), `nslookup`/`dig`, hosts file.
11. NAT and port forwarding; public vs private addressing.
12. Common protocols and ports: HTTP/HTTPS, FTP/SFTP, SSH, SMTP/IMAP, RDP, SNMP.
13. Wireless: standards, frequencies, channels, WPA2/WPA3, coverage planning, interference.
14. Internet access in the Somali context: ISP links, routers, failover between two providers, bandwidth sharing.
15. Troubleshooting method: `ping tracert ipconfig/ip nslookup netstat`, working layer by layer.
16. Documentation: network diagram, IP address plan, cable schedule.

**Practical labs:** make and certify 20 cables · build a 3-switch network and prove connectivity · subnet a /24 for five departments and implement it · DHCP and DNS configuration · Wi-Fi survey and channel selection · fault-injection lab (instructor plants 8 network faults).

**Course project:** *Network Design Pack for a 30-User Office* — floor plan, cable schedule, device list with costing, IP address plan, VLAN/department layout, and a working scaled-down build in the lab.

**Assessment:** Practical exam 40% · Labs 30% · Subnetting test 15% · Attendance 10% · Design documentation 5%

#### IT-203 · Advanced Excel & Data Handling
**24 hours · Prerequisite: IT-103**

*What the student can do at the end:* turn a messy list of business data into a clean, analysed, presentable report.

**Topics**

7. Importing data from CSV and from the web; Power Query introduction.
8. Protecting workbooks, sharing safely, and printing a board-ready report.
9. Introduction to what a database is, and when to stop using Excel (bridges to IT-402).

**Course project:** *Sales & Inventory Dashboard* — take a supplied 2,000-row raw dataset, clean it, analyse it, and deliver a one-page dashboard plus a written two-paragraph finding.

**Assessment:** Practical exam 50% · Project 30% · Labs 10% · Attendance 10%

#### IT-301 · Office Network, Server & Printer Setup
**60 hours · Prerequisites: IT-102, IT-201, IT-202**

*What the student can do at the end:* walk into an empty office and leave it with a working, shared, printing, backed-up network.

**Topics**

7. File services: shared folders, NTFS vs share permissions, department drives, mapped drives by login script or GPO.

9. **Printing:** printer types and total cost of ownership; installing a network printer; static IP for printers; sharing via a print server; installing drivers to 20 clients; scan-to-folder and scan-to-email; troubleshooting print queues, spooler faults and paper/toner issues.
10. Shared internet: bandwidth management, fair usage, blocking, monitoring.
11. Backup for the office: what to back up, 3-2-1 rule, on-site plus cloud, restore testing.
12. Remote support: RDP, AnyDesk/TeamViewer, remote troubleshooting etiquette.
13. Running a help desk: ticket logging, priority levels, SLA, escalation, asset register.
14. Handover: as-built documentation, password register, user training session, support agreement.

**Practical labs:** full office build in the lab (cabinet to desktop) · domain join 5 clients and apply a GPO · network printer install and deploy to all clients · restore-from-backup drill · one week of live help-desk rotation supporting other MPC classes.

**Course project:** *Turnkey Office Deployment* — in teams of three, build a complete 10-user office network in the lab from empty racks, then hand it over to a second team who must operate it from the documentation alone. The documentation is graded by whether the second team succeeds.

**Assessment:** Practical exam 40% · Team build 25% · Documentation 15% · Help-desk log 10% · Attendance 10%

#### IT-302 · IT Security & Data Protection Essentials
**36 hours · Prerequisites: IT-102, IT-202 · Aligned to CompTIA Security+ awareness level**

*What the student can do at the end:* secure a small office to a defensible baseline and explain the risks to a non-technical owner.

**Topics**

1. Why attacks happen: threat actors, motives, and what actually targets small businesses.
2. The CIA triad in plain language; risk = likelihood × impact.
3. Passwords and identity: password rules that work, password managers, MFA, account lockout.
4. Social engineering: phishing, vishing, fake invoices, WhatsApp scams, mobile-money fraud — with local examples.
5. Malware: viruses, worms, trojans, ransomware; how infection actually happens; response procedure.
6. Endpoint hardening: patching, antivirus, disk encryption (BitLocker/LUKS), screen lock, USB policy.
7. Network security: firewall rules, changing default credentials, disabling WPS, segmenting guest Wi-Fi, VPN basics.
8. Web and email security: HTTPS and certificates, SPF/DKIM/DMARC introduction, spam filtering.
9. Physical security: server room, locks, CCTV, visitor control, secure disposal of disks.
10. Backup as a security control; ransomware recovery drill.
11. Data protection and privacy: what personal data is, retention, consent, confidentiality for a client's data.
12. Incident response for a small business: detect, contain, eradicate, recover, learn; who to call.
13. Writing a one-page IT security policy an owner will actually sign.
14. Professional ethics: the technician's power over client data, and the boundaries that go with it.

**Practical labs:** phishing-email identification drill · hardening checklist applied to a real lab PC and audited by a peer · ransomware simulation and restore-from-backup race · router hardening.

**Course project:** *Security Assessment & Policy* — assess a supplied (deliberately weak) office setup, produce a findings report with severity ratings, remediate what can be remediated in the lab, and deliver a one-page signed security policy.

**Assessment:** Practical exam 35% · Assessment report 35% · Labs 20% · Attendance 10%

#### IT-403 · Hosting, Domains & Going Live
**18 hours · Prerequisites: IT-303, IT-402**

*What the student can do at the end:* buy a domain and hosting for a client and put a live, secure, professional site on the internet.

**Topics**

1. What hosting is: shared, VPS, cloud, dedicated — choosing for a client's budget and traffic.
2. Domain names: TLDs, `.so` and `.com` registration, registrars, pricing, renewal, WHOIS privacy, ownership in the client's name (not yours).
3. DNS in practice: nameservers, A, CNAME, MX, TXT records, propagation, common mistakes.
4. cPanel walkthrough: file manager, FTP accounts, databases, subdomains, addon domains, cron, backups.
5. Deploying a site: FTP/SFTP with FileZilla, folder permissions, `.htaccess` basics, custom error pages.
6. Deploying a PHP/MySQL app: exporting and importing the database, editing the connection file, fixing paths, debugging live.
7. SSL/HTTPS: free certificates (Let's Encrypt), installing, forcing HTTPS, mixed-content fixes.
8. Business email: creating mailboxes, connecting Outlook and phones, SPF/DKIM so mail is not marked spam.
9. Going live checklist: backups, uptime monitoring, analytics, Search Console, sitemap, favicon, contact form delivery.
10. Maintenance and the commercial side: renewals, updates, a simple maintenance contract, and what to charge.
11. Alternatives: GitHub Pages, Netlify, and cloud free tiers for small projects.

**Practical labs:** register a real (or sandbox) domain and point it · migrate the IT-402 project from XAMPP to live hosting · fix three broken deployments prepared by the instructor.

**Course project:** *Live Client Site* — the Term 3 or Term 4 project deployed to real hosting on a real domain, with HTTPS, working email, and a handover document for the client.

**Assessment:** Live deployment 50% · Practical exam 25% · Handover document 15% · Attendance 10%

#### IT-404 · Capstone Project, Portfolio & Career Readiness
**18 hours · Prerequisite: all preceding courses**

*What the student can do at the end:* prove what they can do, to an employer, in an interview.

**Topics**

1. Capstone scoping: choosing a real client or a realistic scenario that uses both infrastructure and web skills.
2. Project management for one person: scope, milestones, a simple Gantt, tracking your own work.
3. Client communication: requirements meeting, written proposal, change requests, saying no politely.
4. Technical documentation and the as-built pack.
5. Portfolio construction: a personal website presenting five to seven projects with problem, action, result.
6. GitHub profile, README writing, and a clean commit history.
7. CV and cover letter for the Somali and remote-freelance markets; LinkedIn profile.
8. Interview preparation: technical questions per role, whiteboard troubleshooting, and answering "I don't know" well.
9. Freelancing basics: quoting, invoicing, contracts, mobile-money payment, managing a client relationship.
10. Continuing study: which certification to take next and why (see Section 8).

**Capstone (mandatory for the Diploma):** a single deliverable that combines infrastructure and web work — for example: set up a small business's network, PCs and printer, **and** build and deploy its website with an online booking or inventory system. Submitted as working system + documentation + presentation.

**Assessment:** Capstone system 40% · Capstone documentation 20% · Panel presentation 20% · Portfolio & CV 15% · Attendance 5%

*(Thirteen units; IT-403 and IT-404 are short units that together occupy the final four weeks.)*

### 5.2 Why this order and not another

- **Hardware before software.** A student who has never opened a case cannot diagnose a boot failure. IT-101 must be first.
- **Windows before Linux.** Students arrive knowing Windows. Linux is easier once installation, partitioning and file systems are already understood in a familiar environment.
- **Office software early, and in parallel.** IT-103 has no technical prerequisite and gives students a sellable skill in the first three months. It also keeps less confident students engaged while the hardware content is demanding. This is deliberate retention design.
- **Networking after operating systems.** Configuring an IP address means little until you have installed the OS that holds it.
- **Office infrastructure (IT-301) only after Windows, Linux and networking.** It is the integration course — it fails if any of the three is missing.
- **Security after networking, before the web.** Students must understand a network before securing it, and must carry security habits into their web development, not learn them afterwards.
- **Web design before JavaScript before PHP.** Structure, then behaviour, then data. Skipping ahead produces students who copy code without understanding it.
- **Hosting after the application exists.** There is nothing to deploy until IT-402 is done.
- **Capstone last, and it must span both halves of the program** — this is what makes the graduate a *broad* junior IT engineer rather than either a repair technician or a web designer.

The capstone is the only course that requires both, and that is deliberate — it is what separates an MPC graduate from a technician who only fixes PCs or a designer who only makes pages.

## 6. The Certificate Model

This is the part the current MPC page leaves open, and it is where most of the commercial value sits.

### 6.1 Five levels of award

| Award | Requirement | What it says |
|---|---|---|
| **MPC Course Certificate** | Pass any single course | "Completed *Office Productivity & Digital Documents*, 36 hours, with grade B." Issued for every course, including to students who enrol in that course alone. |
| **MPC Certificate — Computer & Office Operations** | Term 1 complete (IT-101, 102, 103 — 144 h) | Can install and support Windows PCs and produce professional business documents. Employable as an office assistant or lab technician. |
| **MPC Certificate — IT Support & Networking** | Terms 1 + 2 complete (288 h) | The **6-month intensive exit award.** Can support Windows and Linux machines and build a small network. |
| **MPC Certificate — IT Infrastructure Support** | Terms 1 + 2 + 3 complete (432 h) | Can deploy and secure a complete office network with servers and printing. |
| **MPC Professional Diploma in Information Technology (Junior IT Engineer)** | All 13 courses + capstone passed (576 h) | The full award. Infrastructure and web development, with a defended capstone. |

**Design principle:** every stage is a real exit point with a real award. A student who runs out of money after six months still leaves with a certificate that names skills an employer recognises — and with a documented path back in.

### 6.2 Requirements for any certificate

A certificate is issued only when **all four** conditions are met:

| Condition | Threshold |
|---|---|
| Attendance | **≥ 75%** of scheduled contact hours for that course |
| Overall course grade | **≥ 60%** |
| Practical exam | **≥ 60%** — a failed practical cannot be compensated by written marks |
| Course project | Submitted, accepted, and added to the student's portfolio |

For the Diploma, additionally: **all 13 courses passed**, capstone passed at ≥ 60%, and the panel presentation delivered.

### 6.3 Assessment structure — the same shape in every course

| Component | Typical weight | Form |
|---|---|---|
| Practical exam | 35–50% | Timed, on real equipment or a real machine. The student *does* the task; the examiner scores the outcome against a checklist. |
| Course project | 25–40% | The portfolio piece described in each course above. |
| Continuous labs | 10–30% | Weekly lab sheets, signed off by the instructor. |
| Written / knowledge test | 10–20% | Multiple choice and short answer, aligned to certification objectives. |
| Attendance | 5–10% | Recorded per session. |

**Rule:** no course is assessed by written examination alone. Every course ends with the student performing the job task.

### 6.4 Grading scale

| Grade | Marks | Meaning |
|---|---|---|
| A — Distinction | 85–100 | Works independently; quality an employer would accept without rework. |
| B — Merit | 70–84 | Competent; needs occasional guidance. |
| C — Pass | 60–69 | Meets the minimum standard for the task. |
| F — Fail | below 60 | Must repeat the course or the failed component. |

**Re-sits:** one re-sit permitted per course, within four weeks, capped at grade C. A second failure requires repeating the course.

### 6.5 What is printed on the certificate

Front:

- Student full name and MPC student number
- Award title (course name or stage award)
- Contact hours and dates of study
- Grade achieved
- Unique certificate number and QR code linking to an online verification page
- Signatures: Programme Director and Principal, plus the MPC seal

Back (or attached transcript):

- The list of learning outcomes achieved
- The component marks
- The project title completed

**Recommendation:** build the verification page on mpc.so (`mpc.so/verify/<certificate-number>`). It costs one small database table, and it is the difference between a certificate an employer trusts and one they do not. It is also a natural build exercise for IT-402 students.

### 6.6 Attendance and progression policy (suggested wording for publication)

- Sessions are 2.5 hours; attendance is taken at the start and after the break.
- Below 75% attendance in a course: no certificate for that course, regardless of marks. The course may be repeated once at 50% fee.
- Three consecutive unexplained absences trigger a counselling meeting with the Programme Director.
- A student who fails two courses in the same term repeats the term.
- Fees, if paid per term, must be cleared before certificates for that term are released.

Keep one weekly session labelled **"project clinic"** in every term — unstructured lab time with an instructor present. It is where the portfolio actually gets built, and it is what students remember.

24 hours/week · 12 weeks per term compressed into 24 weeks total · 288 hours · exits with the **MPC Certificate in IT Support & Networking**.

Same courses, same assessments, same certificates. A graduate may re-enter at Term 3 at any later intake with full credit.

## 8. Certification Alignment and the Specialisation Layer

### 8.1 How the core courses map to international exams

| MPC course | Maps to | Coverage |
|---|---|---|
| IT-101 | CompTIA ITF+; A+ Core 1 hardware domains | ~70% of Core 1 hardware objectives |
| IT-102 | CompTIA A+ Core 2 | ~75% of Core 2 objectives |
| IT-201 | CompTIA Linux+ | ~50% — foundation level |
| IT-202 | CompTIA Network+ (N10-009) | ~70% |
| IT-301 | A+ Core 2 + Network+ operational domains | Integration and practice |
| IT-302 | CompTIA Security+ | Awareness level, ~35% |
| IT-303/401/402/403 | No single vendor exam | Portfolio and live deployment are the evidence |

**Note for the printed prospectus:** exam codes and versions change. Confirm the current codes with CompTIA and Cisco before printing. At the time of writing the current versions are A+ **220-1201 / 220-1202** (V15), Network+ **N10-009**, Linux+ **XK0-006**, and CCNA **200-301 v1.1**.

### 8.2 Specialisation courses — after the Diploma, not instead of it

MPC already advertises CompTIA A+, CCNA 200-301 and Data Analysis. Position them explicitly as **Level 2**, taken after the Diploma or by candidates who already have equivalent experience:

| Specialisation | Hours | Prerequisite | Leads to |
|---|---|---|---|
| CompTIA A+ Exam Preparation | 60 | IT-102 | A+ certified technician |
| Cisco CCNA 200-301 | 120 | IT-202 | Network engineer, ISP roles |
| Data Analysis (Excel, SQL, Power BI) | 90 | IT-203, IT-402 | Data analyst |
| Cybersecurity Practitioner | 90 | IT-302 | SOC analyst, security officer |
| Advanced Web Development (Laravel or React) | 120 | IT-402 | Full-stack developer |
| Cloud Fundamentals (AWS / Azure) | 60 | IT-201, IT-202 | Cloud support associate |
| Graphic Design & Digital Marketing | 60 | IT-103 | Designer, social media officer |

Removing the duplication is the key move: because IT-102 and IT-202 already cover most of A+ and Network+, the exam-prep courses become short, cheap and high-margin rather than full re-teaches.
