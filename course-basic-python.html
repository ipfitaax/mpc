Basic Python Programming

Learn the fundamentals of programming using Python — from variables and logic to small working programs.

Duration: 10 weeks Format: In-person, Soobe Level: Beginner

What You'll Learn

Python syntax, variables, and data types

Control flow: conditionals and loops

Functions, lists, and dictionaries

Building and debugging small programs

Weekly Curriculum

A week-by-week plan across the 10-week course.

Week
What You'll Learn

Conditionals: if, elif, and else statements.

Week 4
Loops: for and while loops.
Number pattern or counting program using loops.
Week 5
Functions: writing and calling reusable code.
Small toolkit of reusable functions.
Week 6
Lists: storing and working with collections of data.
To-do list manager using lists.
Week 7
Dictionaries: storing structured, labeled data.
Simple contact book using dictionaries.
Week 8
Working with files: reading and writing text data.
Program that saves and loads data from a file.
Week 9
Debugging and planning the final project.
Draft version of the final Python project.
Week 10
Finishing and presenting the final project.
Completed, working Python program with a short demo.

Who This Course Is For

Beginners who want a first, practical introduction to programming logic before moving into web development, data analysis, or further software study.
